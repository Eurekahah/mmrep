# P7 几何指标定义

本文与 `metrics/geometry.py` 的实现对应，规定输入口径、公式和结果解释方式。指标用于比较**同一模型内部**不同微调设置或扰动条件；CLIP 与 SigLIP 的嵌入维度、训练和预处理不同，不直接比较两者的绝对指标值。

## 通用约定

- 图像嵌入记为 $x_i\in\mathbb{R}^D$，第 $i$ 张图的第 $j$ 条 caption 嵌入记为 $y_{ij}\in\mathbb{R}^D$，本项目每图有 5 条 caption。
- 除另有说明外，输入向量逐行做 L2 归一化：$\hat z=z/\|z\|_2$。特征文件中的 `img_raw`、`txt_raw` 未归一化。
- 指标按同一数据集、split、模型和设置计算。条件（`clean`、`noise`、`occl` 等）之间使用相同样本顺序。
- 数学定义默认假设向量范数非零。代码对零向量使用极小分母保护；零向量经此处理仍为零，其指标解释不再等同于单位球面上的几何量，应避免此类输入。

## 图文对齐

逐图配对图像与第一条 caption。特征文件中第一条 caption 的索引为 `txt_raw[0::5]`。

### 余弦距离 `alignment_cos`

$$A_{\cos}=\frac{1}{N}\sum_{i=1}^{N}\left(1-\hat{x}_i^\top\hat{y}_{i1}\right).$$

值域为 $[0,2]$；越小越好。0 表示每对方向一致，1 表示平均余弦相似度为 0，2 表示每对方向相反。

### Wang–Isola 距离 `alignment_w`

$$A_{W,\alpha}=\frac{1}{N}\sum_{i=1}^{N}\|\hat{x}_i-\hat{y}_{i1}\|_2^\alpha,$$

默认 $\alpha=2$。单位向量的平方欧氏距离等于 $2(1-\cos)$，所以默认值域为 $[0,4]$，越小越好。一般 $\alpha>0$ 时值域为 $[0,2^\alpha]$。

## 均匀性 `uniformity`

图像和文本各自独立计算。图像侧输入 N 条图像嵌入；文本侧使用全部 5N 条 caption 嵌入，不先按图聚合。

$$U_t(Z)=\log\left(\frac{1}{|P|}\sum_{(i,j)\in P}\exp\left[-t\|\hat z_i-\hat z_j\|_2^2\right]\right),$$

其中 $P$ 是所有 $i<j$ 的无序样本对，$t>0$，默认 $t=2$。当总样本对数不超过 `max_pairs`（默认 5000）时使用全部样本对；超过时以 `seed`（默认 42）抽取互不重复的无序样本对。抽样是对成对核值均值的子采样估计，固定种子可复现。单位向量时 $U_t\leq0$；数值越低（越负）表示平均核相似度越低、嵌入越分散。该指标依赖 $t$、样本量和采样设置，比较时应固定这些参数。

## 模态间隙

### 质心距离 `modality_gap`（主指标）

分别对图像和全部 caption 向量逐行归一化，计算两模态质心的欧氏距离：

$$G=\left\|\frac{1}{N}\sum_{i=1}^{N}\hat{x}_i-\frac{1}{5N}\sum_{i=1}^{N}\sum_{j=1}^{5}\hat{y}_{ij}\right\|_2.$$

值域为 $[0,2]$。0 表示质心重合，数值越大表示质心越分离。它只度量一阶均值差异，不足以描述两种分布的全部差异，也不等同于分类可分性。

### 线性探针 `gap_linsep`（辅助指标）

将图像和文本嵌入分别标为两类，以 `StandardScaler` 和逻辑回归组成 pipeline，通过分层交叉验证预测模态标签。默认最多 5 折；若某模态少于 5 个样本，折数降为较少模态的样本数；每个模态至少需要 2 个样本。标准化器在每折训练集内拟合。结果为各折普通准确率的均值，范围 $[0,1]$；越高表示线性分类器越容易区分模态，约 0.5 接近二分类机会水平。由于图像有 N 条、文本有 5N 条，评估集类别不平衡，普通准确率可能受多数类影响；须结合质心距离解释。

## 类别原型（COCO）

COCO 标签取每张图中面积最大的实例类别。函数 `prototypes(img, txt, labels, min_count=20)` 支持两种文本输入：每图一条 `[N,D]`，或按图连续排列的原始 caption `[5N,D]`。对 `[5N,D]` 输入，先逐条 L2 归一化，再将每图五条 caption 向量取均值并重新归一化，形成图像级文本向量。之后按类别分别对图像向量和图像级文本向量取均值，并将类均值归一化，得到原型 $p_c^I$ 与 $p_c^T$。

只保留当前 split 中图像数不少于 20 的类别。函数返回类别到原型对的映射，不返回类别频数；需要加权汇总时，调用方需用相同标签统计各类别样本数，并传给汇总函数。阈值和保留类别按 split 单独确定，因此 val 与 test 的类别集合可能不同。

### 原型距离 `proto_distance`

对两个原型映射中共有的类别计算：

$$d_c=1-(p_c^I)^\top p_c^T.$$

单类距离在 $[0,2]$，越小越好。返回 `mean`（类别宏平均）和 `median`（类别距离中位数）；传入 `sample_counts` 后还返回 `weighted_mean`，按共有类别的图像数加权。中位数不做样本加权。

### 原型最近邻准确率 `proto_nn_acc`

对每个保留类别的图像原型，在共有类别的文本原型中按余弦相似度选最近类别：

$$\hat c(c)=\arg\max_{c'}(p_c^I)^\top p_{c'}^T.$$

返回 `mean`（类别宏平均准确率）；提供 `sample_counts` 时另返回 `weighted_mean`（按共有类别图像数加权）。值域 $[0,1]$，越高越好。并列最大相似度时，代码按原型映射中的类别顺序选择第一个类别。

## Bootstrap 置信区间 `bootstrap_ci`

函数对输入数组的首轴进行有放回重采样，默认重复 200 次、随机种子 42，返回百分位区间 `(low, high)`。默认 `confidence=0.95`，对应经验分布的 2.5% 和 97.5% 分位数。所有输入数组必须等长并按行对齐；每轮共用一组重采样索引，以保持逐样本配对。可用于对齐指标（图像与第一条 caption 均为 `[N,D]`）或对单一模态重算均匀性。

原始文本为 `[5N,D]`，不能与图像 `[N,D]` 直接作为同一轮 bootstrap 的输入。模态间隙涉及不同数量的图像与文本样本，当前通用函数不提供两模态独立或分层重采样；跑批代码如需间隙置信区间，应明确实现相应的重采样方案，不能将其当作已由此函数自动计算。

## 结果报告建议

每个结果至少标注数据集、split、模型、设置、条件和所用参数。对比扰动时报告相对 clean 的变化；跨模型优先比较相对变化，不将绝对嵌入几何值直接解释为模型优劣。原型结果同时给出类别宏平均和按样本数加权值，以便观察类别不均衡对总体结果的影响。
